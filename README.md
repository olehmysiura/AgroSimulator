# AgroSim UA — Віртуальна лабораторія агронома

Інтерактивний навчальний веб-симулятор для викладання агрономії в аграрних ЗВО та коледжах України.
Суто науково-практичний фізико-біологічний симулятор: **без економіки, валюти чи цін**.

## Запуск

```bash
npm install
npm run dev        # режим розробки
npm run build      # перевірка типів + продакшн-збірка в dist/
npm run preview    # перегляд збірки
```

Стек: React 19 + TypeScript, Vite, Tailwind CSS v4, `lucide-react`, SVG-графіка.

## Архітектура (State-Driven Simulation)

```
src/sim/            ← ядро, без залежностей від React
  types.ts          стан симуляції (6 горизонтів ґрунту, погода, культура, журнал, квест)
  data.ts           зони (Полісся / Лісостеп / Степ), 6 культур, шкали BBCH↔САТ, агрегати, прилади
  weather.ts        детермінований кліматичний генератор + режими (злива, посуха, приморозок, вітер)
  soil.ts           водний баланс «каскад відер», інфільтрація, підплужна підошва, опір пенетрації, азот
  engine.ts         tick() — 1 день: погода → ґрунт → бур'яни → культура (BBCH, коріння, вода, N, хвороби)
  operations.ts     посів, обробіток ґрунту, ЗЗР/живлення + миттєвий «Розбір агрономічної помилки»
  diagnostics.ts    визначення активної кризи та релевантності лабораторного приладу
  quests.ts         4 кризові сценарії (лише об'єктивні симптоми в описі)
  reducer.ts        кожна дія студента = клон стану + перерахунок фізики
src/components/     5 функціональних зон інтерфейсу + модальні вікна приладів і звіту
```

`Tick = 1 день`. Кожна дія та кожен день перераховують вологість, щільність, опір і азот
6 горизонтів (0–2, 2–8, 8–30, 30–35, 35–80, 80–150 см), погоду, фітосанітарний стан і фазу BBCH.
Ключова фізика:

* Підплужна підошва з ефективним опором **≥ 3,0 МПа** блокує ріст коріння (L-подібний вигин,
  «хвостатість» цукрового буряка) та інфільтрацію — вода застоюється в горизонті A.
* Злива ≥ 22 мм на ґрунті без мульчі формує кірку; проростки під нею «штопорять» і гинуть.
* Точка росту кукурудзи до BBCH 16 знаходиться під землею (2,5 см) і переживає приморозок −2 °C.
* Вечірня зміна з інжекторними розпилювачами знижує робочий вітер до 2,1 м/с.

«Машина часу» зберігає знімки стану по днях: повзунок назад повертає поле в минуле,
вперед — досимульовує дні.

## Педагогічні принципи

* В описах викликів та вікнах приладів — **лише симптоми й сирі дані**, без підказок.
* Будь-яка технологічна помилка негайно відкриває червоний блок **«РОЗБІР АГРОНОМІЧНОЇ ПОМИЛКИ»**
  (що зроблено, фізико-біологічна причина, наслідки) і змінює стан симуляції.
* Прилад, що не відповідає поточному симптому, показує попередження, чому він не дає відповіді.
* «Атестаційний звіт» — інтегральний бал, шкала ECTS, розбір помилок, виклики, прогноз урожаю, друк.

## Кризові сценарії

1. Повітряна посуха та ґрунтова кірка після зливи (соняшник BBCH 07–09).
2. Нічний приморозок −2 °C по сходах кукурудзи (BBCH 13).
3. В'янення рослин за наявності вологи в глибоких шарах (підошва 3,6 МПа на 30 см).
4. Спалах септоріозу пшениці при шквальному вітрі 9,5 м/с (BBCH 39).
