# AgroSim UA — Віртуальна лабораторія агронома

Інтерактивний навчальний веб-симулятор для викладання агрономії в аграрних ЗВО та коледжах України.
Суто науково-практичний фізико-біологічний симулятор: **без економіки, валюти чи цін**.

## Запуск

```bash
npm install
npm run dev        # режим розробки
npm run build      # перевірка типів + продакшн-збірка в dist/
npm run preview    # перегляд збірки
```

Стек: React 19 + TypeScript, Vite, Tailwind CSS v4, `lucide-react`, SVG-графіка.

## Архітектура (State-Driven Simulation)

```
src/sim/            ← ядро, без залежностей від React
  types.ts          стан симуляції (6 горизонтів ґрунту, погода, культура, журнал, квест)
  data.ts           зони (Полісся / Лісостеп / Степ), 6 культур, шкали BBCH↔САТ, агрегати, прилади
  weather.ts        детермінований кліматичний генератор + режими (злива, посуха, приморозок, вітер)
  soil.ts           водний баланс «каскад відер», інфільтрація, підплужна підошва, опір пенетрації, азот
  engine.ts         tick() — 1 день: погода → ґрунт → бур'яни → культура (BBCH, коріння, вода, N, хвороби)
  operations.ts     посів, обробіток ґрунту, ЗЗР/живлення + миттєвий «Розбір агрономічної помилки»
  diagnostics.ts    визначення активної кризи та релевантності лабораторного приладу
  physiology.ts     фактори росту, біомаса, LAI, азотний баланс, модель урожаю, облік втрат
  anatomy.ts        будова насінини й органів, стани за фазами, етапи органогенезу
  soilscience.ts    фази, гранулометрія, хімічний склад, вбирний комплекс, фізичні процеси
  quests.ts         12 ситуаційних викликів, оцінювання рішень, еталонні рішення для викладача
  reducer.ts        кожна дія студента = клон стану + перерахунок фізики
src/components/     5 функціональних зон інтерфейсу + модальні вікна приладів і звіту
```

`Tick = 1 день`. Кожна дія та кожен день перераховують вологість, щільність, опір і азот
6 горизонтів (0–2, 2–8, 8–30, 30–35, 35–80, 80–150 см), погоду, фітосанітарний стан і фазу BBCH.
Ключова фізика:

* Підплужна підошва з ефективним опором **≥ 3,0 МПа** блокує ріст коріння (L-подібний вигин,
  «хвостатість» цукрового буряка) та інфільтрацію — вода застоюється в горизонті A.
* Злива ≥ 22 мм на ґрунті без мульчі формує кірку; проростки під нею «штопорять» і гинуть.
* Точка росту кукурудзи до BBCH 16 знаходиться під землею (2,5 см) і переживає приморозок −2 °C.
* Вечірня зміна з інжекторними розпилювачами знижує робочий вітер до 2,1 м/с.

«Машина часу» зберігає знімки стану по днях: повзунок назад повертає поле в минуле,
вперед — досимульовує дні. Шкала часу починається з обраної дати сезону (1 березня,
1 квітня, 25 квітня, 20 липня, 1 вересня) і триває 2 роки, тож озимі від сівби восени
до збирання наступного літа повністю вкладаються в один сеанс. Дата показується з роком.

### Реалістичність моделі

* Погода з «пам'яттю»: температурні аномалії тривають кілька діб, опади групуються в
  дощові/сухі синоптичні періоди, сезонний максимум опадів улітку, сніг за t < 0 °C.
* Сніговий покрив накопичує воду взимку й віддає її навесні; мерзлий ґрунт не вбирає воду.
* Перерозподіл вологи між горизонтами, «закриття вологи» боронуванням, транспірація бур'янів.
* Фізична стиглість ґрунту: навесні поле доводиться чекати, доки горизонт A підсохне до ≤ 80% НВ.
* Хвороби залежать від тривалості зволоження листка; шкідники — від культури
  (павутинний кліщ у спеку, ріпаковий квіткоїд у бутонізацію), вилягання — від густоти й азоту.
* Осінні заморозки зупиняють налив, озимі можуть вимерзати без снігу.

### Можливості для викладача

* **Скинути все** — повне скидання: нова зона й дата початку сезону, очищення журналу,
  помилок, діагностик, викликів, історії «машини часу» та звіту.
* **Проектор** — збільшений масштаб інтерфейсу для аудиторії.
* Швидкість авто-плину ×1 / ×3 / ×7.
* «Еталонне рішення (для викладача)» — прихований блок у картці виклику.

### Фізіологічна модель (реальний вплив факторів)

* Щоденний приріст біомаси = ФАР × перехоплене світло (LAI, закон Бера–Ламберта) × RUE × **g**,
  де g — добуток коефіцієнтів факторів: вода (ETa/ETm з компенсацією між шарами), аерація,
  спека, холод, бур'яни (гіпербола Казенса), хвороби, шкідники (відносно ЕПШ), ущільнення,
  приморозок — та **мінімального** з елементів живлення (закон Лібіха: N, P, K, мікро, pH).
* Азот — баланс у кг/га: мінералізація гумусу (Q10, вологість), винос за кривою критичного
  розведення (індекс NNI), фіксація бульбочками сої, вимивання, денітрифікація.
* Урожай — модель Єнсена (FAO): продуктивність вегетативної, генеративної фаз і наливу
  в степені чутливості фази. Структура врожаю: густота × елементи продуктивності × маса 1000.
* Облік втрат: кожен фактор і кожна помилка показані в т/га та % («Урожай і фактори»).
* Ґрунт: осідання після обробітку, морозне розпушення, водна й вітрова ерозія,
  залежність міцності підошви від вологості, капілярне підняття.

### Розділи (смуга ліворуч)

Кожен розділ показує лише свої панелі; час і керування сеансом завжди зверху.

* **Поле** — розріз поля, операції (посів, ґрунт, ЗЗР, живлення), перемикач погоди, смужка активного виклику, компактний журнал.
* **Лабораторія** — 11 приладів, згрупованих за призначенням.
* **Виклики** — список із 12 викликів, умови та еталонне рішення для викладача.
* **Рослина** — розріз насінини/зернини від сухого насіння до стиглості; зрізи кореня, стебла, листка, конуса наростання, генеративних органів.
* **Ґрунт** — мікроскоп, фази, гранулометрія, елементний склад, вбирний комплекс, фізичні явища, динаміка.
* **Урожай** — що обмежує ріст, втрати за факторами, структура врожаю.
* **Журнал** — повний бортовий журнал із фільтрами.

## Педагогічні принципи

* В описах викликів та вікнах приладів — **лише симптоми й сирі дані**, без підказок.
* Будь-яка технологічна помилка негайно відкриває червоний блок **«РОЗБІР АГРОНОМІЧНОЇ ПОМИЛКИ»**
  (що зроблено, фізико-біологічна причина, наслідки) і змінює стан симуляції.
* Прилад, що не відповідає поточному симптому, показує попередження, чому він не дає відповіді.
* «Атестаційний звіт» — інтегральний бал, шкала ECTS, розбір помилок, виклики, прогноз урожаю, друк.

## Операції, прилади, ЗЗР

* **Обробіток ґрунту (12):** оранка, чизель, плоскоріз КПШ, strip-till, дискування, лущення стерні,
  культивація, зубове боронування, мульчувач, ротаційна борона, міжрядна культивація, коткування.
* **ЗЗР (8):** ґрунтовий і страховий гербіциди, гліфосат, фунгіцид, інсектицид, акарицид,
  ретардант, десикант. **Живлення (5):** КАС-32, PK, мікродобрива, вапнування, антистресант.
* **Прилади (11):** пенетрометр, бур + вологомір, рамка 1 м², лопатка, N-тестер + лупа, NDVI,
  ґрунтові термометри Савінова, кільцевий інфільтрометр, клейові/феромонні пастки,
  агрохімічний аналіз, агрометеостанція з датчиком зволоження листка.

## Ситуаційні виклики (12)

1. Повітряна посуха та ґрунтова кірка після зливи (соняшник).
2. Нічний приморозок −2 °C по сходах кукурудзи.
3. В'янення рослин за наявності вологи в глибоких шарах (підошва 3,6 МПа).
4. Спалах септоріозу пшениці при шквальному вітрі 9,5 м/с.
5. Пожовтіння пшениці після теплої дощової зими (вимивання нітратів, Полісся).
6. Перезволожене поле: чи виходити з технікою?
7. Холодна весна: коли сіяти кукурудзу?
8. Планування сої на кислому ґрунті (вапнування + інокуляція).
9. Масові сходи бур'янів у кукурудзі.
10. Пошкоджені бутони ріпаку перед цвітінням (квіткоїд, пасіка поруч).
11. Мармурове листя сої в спеку (павутинний кліщ — акарицид, а не інсектицид).
12. Загущена пшениця з надлишком азоту (ретардант у BBCH 30–32).
